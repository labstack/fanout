## Review Focus

The five most likely user-facing failure modes, each with its test:

1. **A clause word, operator or pipe inside quotes, a bracket key, a raw entry or parentheses splits or rewrites the query** (`logs where body:"a | b sort c" attributes['x.by']:y`, `` `coalesce(body,'|')=''` ``). Test: `TestLexClauseWordsInsideDelimitersStayTokens` (Task 1) and `TestLowerPositiveFixtures` rows for `http.target:"/a:b"` and `"http://x:8080/y"` (Task 4).
2. **Prefix negation silently drops rows missing the field, or SQL `!=` silently includes them.** `-http.target:/healthz` must count spans without `http.target`; `http.target!=/healthz` must not; `-http_status_code between 400 and 599` must match a present non-numeric value. Test: `TestTruthTable` on DuckDB rows present-equal, present-different, present-uncastable and missing (Task 11).
3. **A variable set to All removes more or less than the user grouped.** `(service:$service status:error)` drops both; `service:$service status:error` keeps the status filter. Test: `TestLowerEntryBoundaries` (Task 4) and `TestVariablesUnderAllPerConstruct` (Task 11).
4. **Opening a stored dashboard changes its query.** Every default-dashboard and eval-fixture query must format and re-lower to itself under the reported tier with identical `Check` results and entry counts; an oversized text must be complete, `editable: false`, and never submitted to `parse`. Test: `TestRoundTripStoredDashboards` and `TestEditableFalsePreservationThroughEnvelope` (Task 11), `TestFormatEditableFalseIsCompleteAndReasoned` (Task 5).
5. **A 1/1 series displaces a 100/1000 series in a ratio chart's top-6.** `count_if(status:error) / count() as r by service` must rank the supported failure first and report the sub-floor series as ranked last. Test: `TestRankingFixtures` sparse-denominator and neutral cases with `Result.Ranking.below_floor` (Task 6).

```go
package fanql

const Version = 1

type Context uint8
const (
	FilterContext Context = iota
	MeasureContext
)

type Kind uint8
const (
	EOF Kind = iota
	Word       // filter context: any bare run of wordchars (fields, values, keywords, numbers, durations, $vars)
	Ident      // measure context identifier
	Path       // measure context dotted identifier run, one token (user.id, resource.k8s.pod.name)
	String     // quoted literal, either quote; Text is the decoded value
	Raw        // backtick entry; Text is the decoded body
	BracketKey // String immediately after attributes[ or resource[; Text is the key
	Number     // measure context only: 1.5, 1e3
	Punct      // ( ) , : = != <> > >= < <= ~ !~ | [ ] + - * /
	Bad        // with Message and Hint
)

type Span struct {
	Start, End int // code points, end exclusive
}

type Token struct {
	Kind     Kind
	Text     string  // decoded for String/Raw/BracketKey; source text otherwise
	Quote    byte    // '"', '\'' or '`' for String/Raw/BracketKey
	Unclosed bool    // String/Raw/BracketKey that ran to the end of the text
	Ctx      Context
	Span     Span
	Message  string  // Bad only
	Hint     string  // Bad only
}

type Tokens []Token

// Lex never fails and always ends with EOF. It switches to MeasureContext after a
// depth-0 "|" and back to FilterContext at a depth-0 by/every/sort/limit/"|" or
// the end (the clause word itself is a FilterContext Word); "count_if(" enters
// FilterContext until its matching ")" (parentheses inside String and Raw do not count).
func Lex(text string) Tokens
```

- The filter context has no `Number` token: numbers, durations and booleans are `Word` tokens classified by the parser in value position (0.3 rule 8). A leading `-` or `+` is a `Punct`; the parser applies the sign rule (0.3 rule 7). `$service` is one `Word`; `$` followed by anything else is `Bad` `unexpected $`.
- Wordchar rule from 0.2: any rune except whitespace and `| ( ) , : = ! < > ~ " ' ` [ ]`; `-`/`+` are wordchars except as the first rune; `*` only as the whole token; `# { } @` are never wordchars (`@`, `{` and `!` become `Bad` tokens whose messages the parser completes with the following word: `"@http.target" is not a field name; write the attribute without @: http.target`, `{ selectors are not FanQL; write labels as key:value, e.g. service:api`, `! negation is not FanQL; write -service:api`).
- Operators longest-match first: `>=`, `<=`, `!=`, `<>`, `!~` before `>`, `<`, `=`, `~`; a bare `~~` is `Bad` with hint `~~ is SQL LIKE; use like, ilike or ~`.

```go
type Query struct {
	Source     string
	SourceSpan Span
	Where      []Expr // ordered entries (0.6)
	WhereWord  bool   // "where" was present on input
	Stage      *Stage
	Sort       *Sort
	Limit      *Limit
	Span       Span
}

type Expr interface{ Span() Span }
type And struct{ Terms []Expr; At Span }
type Or struct{ Terms []Expr; At Span }
type Not struct{ X Expr; At Span }
type Compare struct{ Field Field; Op string; Value Value; At Span }         // Op: ":" "=" "!=" "<>" ">" ">=" "<" "<=" "~" "!~" (":>" etc. normalised to the comparison)
type In struct{ Field Field; Values []Value; Variable string; Negated bool; At Span } // Negated: SQL "not in"
type Between struct{ Field Field; Lo, Hi Value; Negated bool; At Span }
type Like struct{ Field Field; Pattern Value; Insensitive bool; Negated bool; At Span }
type IsNull struct{ Field Field; Negated bool; At Span }                    // is [not] null
type Exists struct{ Field Field; At Span }                                  // k:*   (-k:* parses as Not{Exists})
type Call struct{ Name string; Args []CallArg; Cmp *Comparison; At Span }   // predicate_call; Name lowercased
type CallArg struct{ Field *Field; Value *Value; Call *Call }
type Comparison struct{ Op string; Value Value }
type FreeText struct{ Value Value; At Span }
type Raw struct{ Text string; At Span }

type Field struct {
	Scope   string   // "", "attributes" or "resource"
	Key     string   // dotted path or bracket key as typed; for a single bare segment, that segment
	Bracket bool
	Single  bool     // one bare segment: column or attributes['ident'], resolved in Task 3
	Ref     *FieldRef // set by Resolve (Task 3)
	At      Span
}

type ValueKind uint8
const (WordValue ValueKind = iota; StringValue; NumberValue; DurationValue; BooleanValue; VariableValue; StarValue)
type Value struct {
	Kind     ValueKind
	Text     string  // as typed (decoded for strings); numbers keep their sign ("-3"); durations keep the unit ("1.5s")
	Stored   string  // set by Resolve: alias-mapped stored spelling, or Text
	At       Span
}

type Stage struct {
	Measures  []Measure
	Histogram *Field
	By        []Field
	Bucket    string // "" when absent; lowercased
	At        Span
}
type Measure struct{ Expr MExpr; Alias string; At Span }
type MExpr interface{ Span() Span }
type MCall struct{ Name string; Args []MArg; At Span }        // Name lowercased
type MArg struct{ Field *Field; Number *float64; Star bool; At Span }
type MCountIf struct{ Filter Expr; At Span }                    // one entry (And, Or or leaf)
type MBinary struct{ Op byte; L, R MExpr; At Span }             // '+' '-' '*' '/'
type MNeg struct{ X MExpr; At Span }
type MConst struct{ Value float64; Text string; At Span }

type Sort struct{ Key string; Ascending bool; At Span }
type Limit struct{ N int; At Span }
```
