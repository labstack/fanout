# Support

Fanout is community-supported open source software.

- Use a bug report for reproducible product defects.
- Use a feature request for broadly useful OSS improvements.
- Use GitHub Discussions for setup questions and deployment advice.
- Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).

Include the Fanout version or image digest, operating system or container
runtime, relevant configuration with secrets removed, and the smallest useful
log excerpt. Public issues are not a safe place for ingest tokens, login links,
session cookies, API keys, SMTP credentials, telemetry payloads, or production
host details.

Commercial support is not implied by this repository, and maintainers do not
promise a response time.
