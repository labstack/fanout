On a Hetzner Cloud ccx33 (8 dedicated vCPUs, 32 GB RAM), with telemetrygen
on a separate ccx33 (8 dedicated vCPUs, 32 GB RAM) in the same location over
a private network, Fanout v2026.10.7-alpha accepted **422,408 mixed
OpenTelemetry items/s for five minutes**. The composition was 51,358 spans,
184,883 log records and 186,178 metric points per second. Every generator
exited successfully, there were zero dropped rows and no restarts, and
`fanout repair verify` validated the Parquet store. The run measured ingest only.

## Setup and measurement

Fanout ran alone on its ccx33 with dedicated AMD EPYC-Milan vCPUs. Both VMs
ran Ubuntu 24.04 in Hetzner's fsn1 location. telemetrygen v0.157.0 sent
plaintext OTLP/gRPC over the private network, using 1,000-item batches and
8 workers per process.

The `publish` preset swept 1, 2, 4, 8, 16, 32 and 64 processes per signal
for traces, logs, metrics and mixed ingest, with three repetitions at each
process count. It then ran one five-minute mixed phase at 32 processes per
signal. Accepted throughput is the change in Fanout's
`fanout_ingest_rows_total` counter over each measured phase.

The suite accepted **584.1 million items** in total: 131,484,819 spans,
217,735,381 log records and 234,835,485 metric points.

## Sustained mixed ingest

The sustained phase ran once for **302.9 seconds**. Fanout averaged
**7.33 CPU cores** and reached **13.5 GiB peak RSS**. The generator host
averaged **7.01 of 8 CPU cores**.

| Signal | Accepted items/s |
|---|---:|
| Spans | 51,358 |
| Log records | 184,883 |
| Metric points | 186,178 |
| Mixed total | 422,408 |

telemetrygen keeps one trace export in flight per process, while log and
metric processes keep eight, producing the measured composition.

The run measured ingest only, using synthetic, highly compressible
telemetrygen payloads. Results describe this hardware.

## Reproduce

From the [fanout-bench](https://github.com/labstack/fanout-bench) repository,
run the Hetzner provisioner with the same release, preset and repetition count:

```sh
scripts/hetzner.sh \
  --fanout-version v2026.10.7-alpha \
  --preset publish \
  --repeat 3
```

Both VMs default to ccx33. The
[publishing guide](https://github.com/labstack/fanout-bench/blob/main/docs/publishing.md)
documents credentials, provisioning, the private network and artifact collection.
