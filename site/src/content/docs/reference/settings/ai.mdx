Every setting below is read once at startup and requires a restart to change.
It is read from the environment variable in the second
column, or from the same key in a YAML configuration file. An unrecognised
`FANOUT_`-prefixed variable is a startup error, so a renamed setting surfaces
as a refusal to start rather than as a default nobody chose.

Fanout also recognizes `ANTHROPIC_API_KEY`, `ANTHROPIC_BASE_URL`,
`OPENAI_API_KEY`, and `OPENAI_BASE_URL`. Other vendor/tool variables are
ignored; only the explicitly selected AI provider's key and endpoint are used.

| Setting | Environment variable | Type | Default |

| `ai.anthropic.api_key` | `ANTHROPIC_API_KEY` | string · secret | — |
| `ai.anthropic.base_url` | `ANTHROPIC_BASE_URL` | string | — |

## Notes

### `ai.anthropic.api_key`

Required when ai.provider is anthropic.

### `ai.anthropic.base_url`

Defaults to https://api.anthropic.com. Fanout appends /v1/messages, preserving any gateway path prefix. Use an HTTP(S) base URL without embedded credentials, a query, or a fragment.

### `ai.model`

Overrides the provider's default: claude-sonnet-5-5 for Anthropic and gpt-6.1-sol for OpenAI. The OpenAI provider expects a reasoning model supporting reasoning.encrypted_content for stateless Responses replay. A 400 rejecting encrypted content is reported as a server-side configuration error; choose a compatible reasoning model with ai.model.

### `ai.openai.api_key`

Required when ai.provider is openai.

### `ai.openai.base_url`

Defaults to https://api.openai.com/v1. Fanout appends /responses, preserving the API version and any gateway path prefix. Use an HTTP(S) base URL without embedded credentials, a query, or a fragment.

### `ai.provider`

Enables chat by selecting exactly anthropic or openai. Empty disables chat.

:::caution[Secrets]
Settings marked `secret` are redacted from Fanout's startup configuration
log. They are still plain environment variables: anything that can read the
process environment can read them.
:::
