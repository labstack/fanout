Every setting below is read once at startup and requires a restart to change.
It is read from the environment variable in the second
column, or from the same key in a YAML configuration file. An unrecognised
`FANOUT_`-prefixed variable is a startup error, so a renamed setting surfaces
as a refusal to start rather than as a default nobody chose.

Fanout also recognizes `ANTHROPIC_API_KEY`, `ANTHROPIC_BASE_URL`,
`OPENAI_API_KEY`, and `OPENAI_BASE_URL`. Other vendor/tool variables are
ignored; only the explicitly selected AI provider's key and endpoint are used.

## Notes

### `smtp.from`

Sets the email sender address; required with SMTP.

### `smtp.host`

Selects the mail server. Host, username, password, and from must all be set to enable SMTP.

### `smtp.password`

Authenticates to the mail server; required with SMTP.

### `smtp.port`

Sets the mail server's positive TCP port.

### `smtp.username`

Authenticates to the mail server; required with SMTP.

:::caution[Secrets]
Settings marked `secret` are redacted from Fanout's startup configuration
log. They are still plain environment variables: anything that can read the
process environment can read them.
:::
