## Get help

Use [GitHub Discussions](https://github.com/labstack/fanout/discussions) for setup
questions and deployment advice. Open an [issue](https://github.com/labstack/fanout/issues)
for a reproducible defect or feature request. Fanout is community-supported;
see [SUPPORT.md](https://github.com/labstack/fanout/blob/main/SUPPORT.md).

Include the version or image digest, operating system or container runtime,
configuration with secrets removed, and a small relevant log excerpt. Exclude
credentials, login links, session cookies, private telemetry and production
host details.

## Contribute

Follow [CONTRIBUTING.md](https://github.com/labstack/fanout/blob/main/CONTRIBUTING.md)
for tools, setup, repository conventions and checks. Run `just check` and
`just test-race` before opening a pull request. First-time contributors must
sign the contributor license agreement before a change can merge.

## Report a vulnerability

Follow [SECURITY.md](https://github.com/labstack/fanout/blob/main/SECURITY.md)
for private reporting. Do not open a public issue for a vulnerability.
