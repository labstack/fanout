## Notes

### `PITOT_AUTH_CODE_SECRET`

Signs sign-in codes and login links; needs at least 32 characters in local mode and to issue or redeem OIDC break-glass links.

### `PITOT_AUTH_MODE`

Selects local sign-in or oidc; each mode validates its prerequisites.

### `PITOT_OIDC_ADMIN_GROUPS`

Lists identity-provider groups mapped to admin, separated by commas.

### `PITOT_OIDC_ALLOWED_DOMAINS`

Lists allowed email domains, separated by commas; wildcard * requires verified email.

### `PITOT_OIDC_ALLOWED_GROUPS`

Lists allowed identity-provider groups, separated by commas.

### `PITOT_OIDC_AUTO_PROVISION`

Creates accounts on OIDC sign-in; requires an allowed group or domain.

### `PITOT_OIDC_CLIENT_ID`

Identifies Pitot's client registration; required in OIDC mode.

### `PITOT_OIDC_CLIENT_SECRET`

Authenticates Pitot's client registration; required in OIDC mode.

### `PITOT_OIDC_DEFAULT_ROLE`

Assigns viewer, operator, or admin to users without a group role mapping.

### `PITOT_OIDC_EMAIL_CLAIM`

Names the claim containing the user's email address.

### `PITOT_OIDC_EMAIL_VERIFICATION`

Selects required verified-email claims or issuer trust; issuer trust requires an allowlist.

### `PITOT_OIDC_ISSUER_URL`

Selects the identity provider issuer; required in OIDC mode. Pitot starts while it is unreachable and retries discovery; a mismatched issuer fails startup.

### `PITOT_OIDC_OPERATOR_GROUPS`

Lists identity-provider groups mapped to operator, separated by commas.

### `PITOT_SCIM_TOKEN`

Enables SCIM 2.0 user provisioning under /scim/v2 and turns off browser setup; requires OIDC mode and at least 32 characters.

### `PITOT_SELF_SIGNUP`

Allows verified email addresses to create viewer accounts; requires local auth and SMTP.

### `PITOT_SESSION_ABSOLUTE_TTL`

Limits total session lifetime; it must be at least PITOT_SESSION_IDLE_TTL.

### `PITOT_SESSION_IDLE_TTL`

Expires inactive sessions; use a Go duration of at least 5m.

:::caution[Secrets]
Settings marked `secret` are redacted from Pitot's startup configuration
log. Supply either the value or its `_FILE` path, never both. File contents
lose exactly one trailing newline (LF or CRLF); empty secrets fail startup.
:::
