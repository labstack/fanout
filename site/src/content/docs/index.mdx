  <Card title="Parquet + DuckDB" icon="document">

  </Card>

  </Card>
  <Card title="MCP server" icon="rocket">
    Twelve tools — `overview`, `topology`, `diagnose`, `trace`, `alerts`, and more — exposed to Claude Code and any MCP client.
  </Card>
  <Card title="Single binary" icon="download">
    No Kubernetes, no Kafka, no Cassandra. Drop the binary on a VM, point a proxy at it, and you're done.
  </Card>
  <Card title="Self-hosted" icon="seti:shell">
    Your data stays yours. Run behind your existing TLS terminator or let Fanout handle certs directly.
